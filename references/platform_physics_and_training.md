# Platform-Specific Physics, On-Chip Training & System Energy/Latency Protocols (`SKILL.md §§16–18`)

## 1. Platform-Specific Physics & Experimental Verification Protocols (`§16`)

Distilled from the **56 `llm_read` hardware landmarks**, every platform has specific physical failure modes that referees audit (`C6`, `C11`, `C14`). Include the corresponding verification protocol in Fig. 2–3 and Methods:

| Platform | Dominant Physical Non-Idealities | Mandatory Characterisation & Calibration Protocol | Required Physics Ablation / Control | Exemplars (`llm_read`) |
|---|---|---|---|---|
| **1. `MZI`** (Coherent meshes) | Thermal crosstalk between adjacent phase shifters; splitter ratio error ($50:50 \pm \Delta$); Fabry–Pérot reflections; $O(N^2)$ insertion loss accumulation | Characterize $V_\pi$ / $P_\pi$ and thermal crosstalk matrix; report matrix fidelity or singular-value accuracy before vs after calibration; state total mesh IL in dB | Compare uncalibrated mesh vs calibrated mesh vs 32-bit digital FP32 baseline on the same test set | `Nature Photonics_17V11_441`; `Science_23V380_398`; `Nature_25V640_361`; `Nature_25V640_368` |
| **2. `MRR`** (Microring weight banks) | Resonance thermal drift ($\Delta\lambda/\Delta T$); inter-channel WDM cross-modulation; Lorentzian nonlinear weight-to-voltage curve; finite $Q$ / ER | Report loaded $Q$, FSR, extinction ratio (dB), and multi-channel weight precision (`bits` = $-\log_2(\sigma_{\text{err}})$) across $>10^3$ random weight pairs | Show open-loop drift vs feedback-stabilized/dithered weight locking or on-chip gradient compensation | `Nature Electronics_21V4_837`; `Nature_22V606_501`; `Nature_25V648_576`; `Nature_26V651_927` |
| **3. `PCM`** (Phase-change crossbar) | Amorphous-to-crystalline state drift; write-pulse energy vs readout optical self-heating; state-dependent insertion loss coupled to phase | Report exact SET and RESET pulse waveforms (voltage/power, width, duty cycle, pulse count), multi-level step repeatability ($32\text{–}64$ levels), and cyclability ($10^3\text{–}10^6$ true switching cycles, not readout cycles) | Measure multi-hour/multi-day state stability and verify probe power is strictly below crystallization threshold | `Nature_19V569_208`; `Nature_21V589_52` |
| **4. `diffractive`** (Free-space & on-chip SOI) | Layer-to-layer 3D alignment error ($\Delta x, \Delta y, \Delta z$); subwavelength feature etching CD tolerance; coupling between shared heaters and multi-port weights | For free-space: quantify lateral/axial misalignment tolerance and diffraction efficiency per layer. For on-chip SOI: validate unit-cell effective index $n_{\text{eff}}(w, T)$ and full-core propagation | **Frozen-core / untrained-core ablation** + **bias-only digital readout baseline** proving task accuracy comes from physical field reconfiguration rather than the linear readout layer | `Science_18V361_1004`; `Nature Photonics_21V15_367`; `Nature Communications_22V13_1044`; `Nature_23V623_48`; `Science_24V384_202` |
| **5. `metasurface`** (Analog & edge vision) | Wavelength dispersion across broadband illumination; angle-of-incidence (NA) roll-off; polarization cross-talk between PB/propagation phases | Measure optical transfer function $H(k_x, k_y)$ or PSF across wavelength and incidence angle; show SEM of nanopillars with CD error | Compare raw camera image vs metasurface-encoded image using a parameter-matched digital CNN | `Science_14V343_160`; `Science_19V363_1333`; `Nature_26V654_917` |
| **6. `microcomb/WDM`** (Kerr comb WDM) | Soliton comb line-to-line power variation; EDFA spontaneous emission noise (OSNR); dispersive fiber delay walk-off | Plot raw vs shaped comb spectrum (dBm per line across all 49–90 lines); verify RF eye diagram and bit precision at the full GHz baud rate | Compare partial-coherence vs full-coherence error resilience (`Nature_24V632_55`) or single-wavelength vs WDM parallel execution | `Nature_21V589_44`; `Nature_24V632_55` |
| **7. `reservoir`** (Delay & spatial RC) | Photodetector/TIA noise floor; memory fade vs nonlinearity trade-off; digital readout overfitting on small time-series splits | Quantify linear memory capacity and nonlinear consistency; use strict disjoint train/validation/test time windows | Compare reservoir output against a direct linear regression / FIR filter trained on the raw input signal (`C5` / `C7` mandatory check) | `Nature Communications_14V5_3541`; `Science_26V394_212` |
| **8. `TFLN`** (Thin-film $\text{LiNbO}_3$) | DC bias photorefractive/pyroelectric drift; RF velocity mismatch at $>50\text{ GHz}$; chip-to-fiber coupling loss | Measure electro-optic $S_{21}$ bandwidth (GHz), $V_\pi L$, and dynamic ENOB vs baud rate (`10–250 GSa/s`) | Show eye diagram / waveform parity error with and without pre-emphasis calibration | `Nature_24V627_80` |
| **9. `spiking`** (Excitable lasers & PCM spiking) | Threshold non-uniformity; refractory timing jitter; cascadability fan-out loss | Report spike threshold energy (pJ), refractory period (ps–ns), and multi-channel spiking synchrony | Show spiking vs non-spiking baseline on temporal sequence classification | `Nature_19V569_208`; `Opto-Electronic Advances_23V6_230140` |
| **10. `Ising`** (OPO CIM & Hopfield) | Pump amplitude fluctuations; FPGA feedback latency in measurement-feedback CIMs; spin trapping in local minima | Plot success probability and time-to-solution ($\text{TTS}_{99}$) as a function of graph size $N$ and edge density | Benchmark $\text{TTS}_{99}$ against optimized Simulated Annealing, Breakout Local Search, or digital heuristic on the exact same graphs | `Science_16V354_603`; `Science_16V354_614`; `Nature_25V648_576`; `Nature_26V657_377` |
| **11. `in-sensor` / `2D-optoelectronic`** | Gate hysteresis in 2D photo-transistors; array pixel-to-pixel responsivity variation; slow persistent photoconductivity | Report multi-cycle conductance repeatability, dynamic range (dB), and array uniformity map | Compare in-sensor analog preprocessing vs conventional frame capture + digital post-processing | `Nature_20V579_62`; `Nature Nanotechnology_19V14_776` |

## 2. Hardware-in-the-Loop & On-Chip Training Playbook (`§17`)

| Training Paradigm | Physical Forward/Backward Mechanism | Hardware Passes per Parameter Update | Requires Digital Twin Model? | Immunity to Unmodeled Drift / Crosstalk | Mandatory Experimental Proof Required by Referees | Canonical `llm_read` Landmarks |
|---|---|:---:|:---:|---|---|---|
| **1. In-Situ Optical Backpropagation (Adjoint / Time-Reversal)** | Forward signal $x$ and backward error signal $e$ counter-propagate through the reciprocal MZI/MRR circuit; interference measures exact $\partial \mathcal{L}/\partial \theta$ | **$2\text{–}3$** optical passes (independent of weight count $W$) | **No** (model-free wave reciprocity) | **High** (measures true physical gradient in situ) | Show forward/backward interference fidelity, bidirectional power calibration, and convergence across $\ge 5$ random initialisations vs digital BP | `Science_23V380_398` (Pai MZI mesh); `Nature_26V651_927` (Ashtiani MRR network) |
| **2. Physics-Aware Training (PAT)** | Forward pass runs on the physical optical hardware; backward pass runs through a differentiable digital twin (`PyTorch`) | **$1$** physical forward pass + **$1$** digital backward pass | **Yes** (differentiable digital proxy) | **High in forward pass** (corrects systematic model-hardware mismatch) | Show PAT outperforms pure *in silico* training when the digital twin is intentionally mismatched or perturbed; replace physical layer with identity to prove non-triviality | `Nature_22V601_549` (Wright et al. 2022) |
| **3. Fully Forward Mode (FFM) / Physical Forward-Forward (PFF)** | Contrastive positive vs negative data passes (or spatial self-interference) optimize local layer goodness without a backward pass | **$2$** physical forward passes (positive + negative / perturbed) | **No** (model-free local contrastive rule) | **High** (no backward path or transpose weight symmetry needed) | Demonstrate multi-layer training convergence and autonomous recovery after injecting strong phase/alignment perturbations | `Science_23V382_1297` (Momeni PFF); `Nature_24V632_280` (Xue FFM); `Nature_25V645_53` (Momeni Review) |
| **4. Perturbation-Based / SPSA / Genetic In-Situ Optimization** | Perturb control voltages $\mathbf{V} \pm \delta\mathbf{V}$ on hardware, measure task loss $\mathcal{L}(\mathbf{V}+\delta\mathbf{V}) - \mathcal{L}(\mathbf{V}-\delta\mathbf{V})$, and update via Adam/SGD | **$2K$** passes (coordinate finite difference for $K$ controls) or **$2$** passes (simultaneous random SPSA probe) | **No** (100% model-free black-box hardware loop) | **Complete** (directly optimizes the coupled physical field + readout) | State exact probe step $\delta V$ and per-step wall-clock latency (DAC settle + thermal equilibration $\tau$ + ADC averaging); include **frozen-core** and **bias-only** baselines; report repeated readout stability on fixed test samples | `Nature Photonics_17V11_441` (Shen); `Nature Communications_22V13_1044` (Zhu); `Nature_25V649_330` (McMahon) |

## 3. End-to-End Energy, Latency & System Boundary Accounting Protocol (`§18`)

$$E_{\text{MAC, boundary}} = \frac{P_{\text{boundary}}}{2 \times R_{\text{MAC/s}}}, \qquad \eta_{\text{TOPS/W}} = \frac{2 \times R_{\text{MAC/s}}}{P_{\text{boundary}}}$$

| Boundary Tag | Included Physical Components | Typical Value Range in `llm_read` Papers | How to Report Honestly in Main Text & Tables |
|---|---|---|---|
| **1. `core_optical`** | Detected or on-chip optical power divided by passive optical MAC rate (excludes laser wall-plug, thermal holding power, and DAC/ADC/TIA) | **$10^{-19}\text{–}10^{-14}\text{ J/OP}$** (`0.49 photons/MAC` in `NC 2022` Wang; `17 fJ/MAC` in `Nature 2021` Feldmann; `13.4 fJ/OP` in `Nature 2023` ACCEL) | Label explicitly as `"optical core energy (excluding laser wall-plug and electronic I/O)"` at first mention in Abstract and Results. |
| **2. `laser_plus_core`** | Laser electrical wall-plug power (or pump + EDFA) + on-chip static thermo-optic holding power | **$0.1\text{–}2.5\text{ pJ/OP}$** (`2.42 pJ/MAC` in `Nature 2025` Shastri; `1.16 pJ/MAC` comb core in `Nature 2021` Xu) | State the measured heater resistance $R(V)$, average holding power per heater, and laser wall-plug efficiency. |
| **3. `chip_electrical_io`** | Laser + photonic core + on-chip/co-packaged DACs, modulator drivers, TIAs, and ADCs | **$1.5\text{–}5.0\text{ pJ/OP}$** (`3.79 pJ/OP` [`263 TOPS/W`] in `Nature 2025` Ahmed Lightmatter; `0.63 pJ/MAC` in `Nature 2021` Feldmann) | List the exact power (mW) and bit resolution/sampling rate of each DAC, driver, TIA, and ADC channel in a component breakdown table. |
| **4. `wall_plug_system`** | Full system wall-plug power including external laser, TEC temperature controller, FPGA/ASIC digital controller, SRAM/DRAM memory fetch, and host interface | **$10\text{–}50\text{ pJ/OP}$** (`14.2 pJ/MAC` [`70.4 GOPS/W`] in `Nature 2021` Xu; `2.95 mJ` per 100 Ising runs at `~23 W` system power in `Nature 2025` Hua PACE) | Report alongside end-to-end task latency against a named GPU/ASIC running the identical workload at batch size 1. |
